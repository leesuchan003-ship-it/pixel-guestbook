# 픽셀 방명록

게임 화면처럼 생긴 결혼식 하객 방명록입니다. 하객이 휴대폰으로 접속해 사진을 올리면
픽셀 캐릭터가 만들어지고, 이름과 축하 메시지를 남기면 식장 화면에 캐릭터가 입장합니다.

- **월드 화면** — 아치 아래 신랑신부, 버진로드 양옆에 흩어져 서성이는 하객 캐릭터. 화면을 끌면 카메라가 움직이고(모바일 터치 포함), 캐릭터를 누르면 말풍선이 뜹니다. 하객들은 제자리에서 계속 서성이고, 축하 메시지를 남긴 사람은 이따금 스스로 말풍선을 띄웁니다.
- **내 캐릭터 조이스틱** — 방명록에 등록하면 화면 왼쪽 아래에 조이스틱이 나타나 내 캐릭터만 따로 걸어다니게 할 수 있습니다(카메라 이동과는 별개 동작). "내 캐릭터" 버튼으로 언제든 되돌아갈 수 있습니다.
- **캐릭터 만들기** — 사진 업로드 → 캐릭터 후보 4종 → 재생성 / 직접 꾸미기 → 이름·대사 입력
- **방명록 목록** — 남겨진 축하 메시지 전체 보기 (누르면 해당 캐릭터로 이동)
- **웨딩 갤러리** — 신랑신부가 올린 사진 모아보기
- **기념 캡처** — 지금까지 모인 하객 전체를 한 장의 "단체사진" PNG로 저장 (스크롤 위치와 무관하게 전체 공간을 찍음)
- **관리자 백업** — 방명록을 JSON 전체 백업 또는 엑셀에서 바로 열리는 CSV 표로 내려받기
- **AI 캐릭터 생성 (선택)** — `OPENAI_API_KEY`를 설정하면 캐릭터 만들기에 "AI로 나와 닮게 만들기" 옵션이 추가로 나타난다. 사진을 실제로 분석해 헤어스타일·안경 유무까지 반영한 캐릭터를 그려준다(색상만 흉내내는 기본 방식보다 훨씬 닮게 나온다). 키가 없으면 이 옵션은 자동으로 숨겨지고 기본 방식만 동작한다.

### 알아둘 점 (하객이 여러 명 동시 접속할 때)

실시간 서버(웹소켓) 없이 동작하도록 만들어서, 하객이 제자리에서 서성이는 움직임과
말풍선이 뜨는 타이밍은 "현재 시각 + 아이디"로 계산됩니다. 그래서 서버에 아무것도
보내지 않아도 모든 사람의 화면에서 같은 순간엔 같은 동작이 보이지만, 조이스틱으로
내 캐릭터를 걷게 하는 움직임은 **내 화면에서만** 보이고 다른 하객 화면에는 실시간으로
반영되지 않습니다(새로고침하면 원래 제자리로 돌아와 있습니다).

## 실행

```bash
cd pixel-guestbook
npm start          # 또는: node server.js
```

`http://localhost:3000` 으로 접속합니다. 설치할 패키지가 없습니다(의존성 0개, Node 18 이상).

환경 변수:

| 변수 | 설명 | 기본값 |
| --- | --- | --- |
| `PORT` | 서버 포트 | `3000` |
| `ADMIN_KEY` | 관리자 비밀번호 | 없으면 `data/admin-key.txt` 에 자동 생성 |
| `DATA_DIR` | 데이터 저장 폴더 | `./data` |
| `OPENAI_API_KEY` | 설정하면 "AI로 닮게 만들기" 옵션이 켜진다 (선택) | 없으면 무료 방식만 동작 |

### AI 캐릭터 생성 설정 (선택)

1. [platform.openai.com](https://platform.openai.com) 에서 API 키를 발급받는다 (Settings → API keys → Create new secret key).
   결제 수단 등록이 필요하다. 사용한 만큼만 청구되며, 하객 1명당 이미지 1장 기준 매우 저렴하다(대략 몇십 원 수준).
2. Render를 쓴다면 대시보드 → Environment → `OPENAI_API_KEY` 추가 → 재배포.
   로컬에서 직접 실행한다면 `OPENAI_API_KEY=sk-... node server.js` 처럼 실행 시 넣어준다.
3. 키를 넣으면 서버 로그에 "AI 캐릭터 생성: 사용 가능"이 뜨고, 하객 화면의 캐릭터 만들기에
   "AI로 나와 닮게 만들기" 버튼이 자동으로 나타난다.

키를 넣지 않으면 이 옵션 자체가 보이지 않고, 기존 무료 방식(색상만 비슷하게)만 그대로 동작한다.
비용이 걱정되면 나중에 언제든 Render 환경 변수에서 키를 지워 끌 수 있다.

## 관리자

배너(상단 문구)를 **1초간 꾹 누르거나** `/?admin` 으로 접속하면 관리자 창이 열립니다.
비밀번호는 서버를 처음 켤 때 터미널에 출력되고 `data/admin-key.txt` 에도 저장됩니다.

관리자로 할 수 있는 일:
- 배너 문구 변경 (예: `민수 ♥ 지영 결혼합니다`)
- 웨딩 갤러리 사진 추가/삭제
- 방명록 삭제 (장난 글 정리용)

## 배포

하객이 접속하려면 인터넷에 올라가 있어야 합니다. **디스크가 유지되는** 호스팅을 쓰세요.
방명록은 `data/db.json` 파일에, 갤러리 사진은 `data/gallery/` 에 저장되기 때문에
매 배포마다 파일이 초기화되는 서버리스 환경(Vercel 등)에는 그대로 올리면 안 됩니다.

### Render / Railway / Fly.io 같은 곳

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Node 서비스로 새 프로젝트를 만들고 시작 명령을 `node server.js` 로 지정합니다.
3. 환경 변수에 `ADMIN_KEY` 를 원하는 비밀번호로 넣습니다.
4. **영구 디스크(Persistent Disk / Volume)를 붙이고** 마운트 경로를 `/data` 로 잡은 뒤,
   환경 변수 `DATA_DIR=/data` 를 추가합니다. 이걸 빠뜨리면 재시작할 때 방명록이 사라집니다.

### 직접 서버(VPS)에 올릴 때

```bash
git clone <저장소 주소> && cd pixel-guestbook
ADMIN_KEY=원하는비밀번호 PORT=3000 node server.js
```

`nginx` 등으로 앞단에 HTTPS를 붙이고, `pm2` 나 `systemd` 로 상시 실행되게 하세요.
**카메라/사진 업로드는 HTTPS에서만 정상 동작**하므로 도메인과 인증서는 꼭 붙여야 합니다.

### 식장에서 쓰는 법

주소를 QR 코드로 만들어 테이블·포토테이블에 두면 하객이 찍고 바로 참여합니다.
식이 끝난 뒤 `data/db.json` 을 백업해두면 캐릭터와 메시지가 그대로 보관됩니다.

## 사진에서 캐릭터를 만드는 방식

원본 서비스는 ComfyUI(이미지 생성 AI)로 사진을 픽셀 캐릭터로 바꾸지만,
그건 GPU 서버가 계속 돌아가야 하고 비용도 듭니다. 이 프로젝트는 **서버 없이**
브라우저 안에서 다음 순서로 캐릭터를 만듭니다.

1. 사진에서 피부색 픽셀을 찾아 얼굴 위치를 추정합니다.
2. 얼굴 위쪽에서 **머리 색**, 얼굴 아래 중앙에서 **상의 색**, 더 아래에서 **하의 색**을 뽑습니다.
3. 얼굴 옆으로 머리색이 이어지는지 보고 **긴 머리/짧은 머리**를 판단합니다.
4. 뽑아낸 색을 그대로 쓰고 헤어스타일·의상만 바꿔 **후보 4종**을 만듭니다.

그래서 "옷 색과 머리 색이 닮은" 캐릭터가 나오고, 안경 같은 세부는 자동으로 잡지 못합니다.
대신 **직접 꾸미기**에서 헤어스타일 12종, 의상 8종, 안경·모자·꽃다발 등을 직접 고를 수 있습니다.
사진은 브라우저 밖으로 나가지 않으며 서버에 저장되지도 않습니다.

## 손대기 좋은 곳

| 하고 싶은 것 | 파일 / 위치 |

## 데이터

```
data/
  db.json          방명록 + 설정 (이 파일만 백업하면 됩니다)
  gallery/         갤러리 사진 원본
  admin-key.txt    자동 생성된 관리자 비밀번호
```

같은 사람이 여러 번 남기지 못하도록 IP당 1시간에 8건으로 제한되어 있고,
이름 12자·메시지 60자로 잘립니다. 바꾸려면 `server.js` 상단 상수를 수정하세요.
